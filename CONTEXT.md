# Settlers to Rust

A reusable skill that translates a C/C++ project into Rust, proven on small libraries first. The long-term goal is a
fully maintained Rust client for The Settlers II (s25client, later possibly widelands), but that is set aside until the
skill works on Pilots.

## Language

**Source project**:
The C/C++ codebase being translated.
_Avoid_: legacy code, original repo, upstream

**Pilot**:
A small library used only to prove the skill works. The C Pilots are jsmn, cJSON, json-parser and miniz; the C++ Pilots
after them are tinyxml2, pugixml and jsoncpp. A Pilot is never the end goal.
_Avoid_: test project, sample, benchmark

**Goal project**:
The large Source project the skill exists for: s25client first, widelands possibly later. Not worked on until the skill
passes its Pilots.
_Avoid_: final target, big project

**Part**:
One logical unit of a Source project (a class, or the file that holds one) that is translated, verified, committed and
resumed as a whole. A single function is too small to be a Part.
_Avoid_: unit, chunk, task, module

**Skill**:
The deliverable: instructions, scripts, and bundled libraries that a Claude Code session follows to translate a Source
project, written generic with a per-Pilot rulebook and Judge.
_Avoid_: tool, pipeline, script

### Stages

**Faithful port**:
Stage 1. A Rust version of the Source project that behaves identically to it and keeps its structure, even if it is
C-shaped or `unsafe`. May keep the C ABI.
_Avoid_: transpile, raw port, C2Rust output

**Idiomatic pass**:
Stage 2. Turns a Faithful port into idiomatic Rust (safe types, Rust error handling, iterators). Drops the C ABI.
Observable behaviour stays the same.
_Avoid_: refactor, cleanup, rewrite, redesign

**Same behaviour**:
For the same input the Rust version gives the same output, including malformed-input cases and error positions. API
shape may differ after the Idiomatic pass. The only permitted exceptions are Deviations.
_Avoid_: same functionality, parity, equivalence

**Attempt**:
One run of an implementer on one Part, ended by the Gate. A Part gets at most five; then it is stubbed.
_Avoid_: try, iteration, round

### Acceptance

**Judge**:
The checks that decide Same behaviour for a Part: the original tests where they can be linked to the Rust code, a
Differential harness, and tests translated into Rust. It says nothing about style or safety.
_Avoid_: oracle, referee, validator

**Differential harness**:
A small driver built once against the original library and once against the Rust crate. It feeds both the same inputs
and diffs their outputs.
_Avoid_: fuzzer, comparison script

**Corpus**:
The input files the Differential harness feeds to both sides. Generated by a script with a fixed seed.
_Avoid_: test data, fixtures, samples

**Adapter**:
The one test-side file that calls the Rust crate, so the translated tests and the Rust driver keep working when Stage 2
changes the crate's API.
_Avoid_: wrapper, shim, binding

**Gate**:
The script that decides one Attempt: the Judge, plus at Stage 2 the acceptance rules (zero `unsafe`, clippy, rustfmt, no
unjustified `unwrap`/`allow`). A failure restores the Part's files; a pass is recorded.
_Avoid_: CI, test run, validation

### Rules of translation

**Rulebook**:
The per-Pilot document of decisions every Attempt follows: mapping overrides, configuration macros, the Rust API,
Deviations and kept Quirks. Read-only during a batch; changed only between batches by Opus or the user.
_Avoid_: style guide, spec, config

**Deviation**:
A place where the Rust version is allowed to differ from the Source project because the original behaviour is undefined
or platform-dependent. Listed in the Rulebook and approved by the user before translation.
_Avoid_: bug, difference, exception

**Quirk**:
A defect-looking behaviour of the Source project that the Rust version reproduces on purpose.
_Avoid_: bug, wart, oddity

**Idiom table**:
The shared list of C constructs with their Rust mapping at each stage and the trap in each. A row is verified only when a
test exercises it.
_Avoid_: cheat sheet, mapping table
