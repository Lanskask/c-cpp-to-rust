## The four delta areas the governor named

1. **parse / parse_with_opts split (Q12, Q13, Q26, D8).** `parse` → `parse_with_opts` → NULL check → reset →
   `parse_counted` with `c_len + 1`; `parse_with_length_opts` resets before its NULL check, as `cJSON.c:1153-1158`. This is the C order
   for all four entry points. The Parser reads past the slice only through `byte` (0 past the end). The only direct
   slices are `parse_number` (the scan stops on a real byte) and `skip_utf8_bom` (`can_access(4)` implies 4 real
   bytes), and both hold. `parse_value` bounds `rest` by `length.min(content.len())`. Measured: 145,018 inputs, both
   slice variants, identical to C, including the error offset after `parse(None)`, `parse_with_opts(None)` and
   `parse_with_length(None)`. Remaining items are markers (row 2) and the D8 text (row 3).
2. **D22 in `apply_patch_in`.** Every path was traced against `cJSON_Utils.c:819-1052` and run (48 cases). NULL `op`
   gives `Invalid` (3). NULL `path` with `test` gives 1. With remove/replace it skips the root branch (`is_some_and`)
   and `detach_path(None)` gives 13. With add it reaches `strdup(None)` = `None` with no event and gives 9, and the
   cleanup deletes the duplicated value. With move it detaches `from` first, then gives 9 and deletes the member. With
   copy it duplicates and then deletes the copy. NULL `from` with move or copy gives 5. A failing `strdup` of a
   non-NULL path gives 9 with no free event, as C. 0 live bytes after every case. Remaining: no test pins the UB
   choices (row 5).
3. **`create_patches` deferred D2 abort.** `alloc_event(size)` sits at C's allocation, the abort comes before each
   `sprintf` (`1188`, `1203`), and `free_event(size)` only fires when the allocation succeeded (C `cJSON_free(NULL)` is
   no event). The early `ULONG_MAX` returns of C are dead on LP64. Measured: 13,199 one-process runs, identical,
   including 615 runs that crash at the same allocation in both.
4. **`Store::remove` retirement.** `checked_add` retires the slot at `u32::MAX`; a retired slot keeps `node = None`,
   so every lookup with any generation gives `None`. Nothing else pushes onto `free`. Measured over 2^32 + 4 reuse
   cycles.
